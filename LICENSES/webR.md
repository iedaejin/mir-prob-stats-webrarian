# webR

This site runs webR 0.6.0 (R 4.6.0).

The webR engine is not part of this site: the page loads it from
<https://webr.r-wasm.org/v0.6.0/> when it opens, under webR's own license
(<https://github.com/r-wasm/webr/blob/v0.6.0/LICENSE.md>).
